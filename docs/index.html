del texto al grafo de conocimiento

Cada tarjeta abre un visor interactivo autónomo: el grafo completo, el texto original con las menciones resaltadas y la evidencia textual de cada relación, todo en un único archivo HTML. Los grafos se construyen con textgraph, que extrae entidades y relaciones de un texto y garantiza que ningún nodo quede aislado.
